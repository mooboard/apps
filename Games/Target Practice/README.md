# Target Practice

Chain saucer hits for bonuses in a cosmic shooting gallery before three misses.

A or B starts again after the game ends. With no game pad it plays itself and starts again on its own.

It runs on the game engine, so its rules, art, and autoplay all live in `data/game.json`. It needs firmware 0.4.0-alpha.3 or later.

## Settings

- Game speed: slow, normal, or fast.
