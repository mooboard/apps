# Lunar Lander

Guide a fragile lunar lander to safely touch down on the moon.

## Implementation status

This source folder is a concept package. Its `uses` still selects the `breakout` renderer. The named behavior needs its dedicated implementation connected before release. The icon refresh does not add that behavior.

## Package

- Category: Games
- Renderer: `breakout`
- Version: 1.0.1
- Minimum firmware: 0.3.1

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
