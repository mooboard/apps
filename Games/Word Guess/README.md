# Word Guess

Find a five-letter word in six attempts. Green means a correct position, amber means a letter elsewhere, and gray means absent. Repeated letters receive credit only as often as they occur in the answer.

The board's local calendar day selects a daily puzzle from a compact built-in dictionary. Without a clock, the display turn's seed selects a practice word. Guesses and progress live for the current turn; they are not saved between turns. The automatic player filters candidates using previous feedback and types its next guess at the chosen Thinking pace. After showing the result, it replays the day's puzzle.

On a board with Gaming enabled, the pad selects a letter from the alphabet grid. Left/Right changes letters; Up/Down moves a grid row. A adds the selected letter, then submits a full five-letter word. B erases. An invalid word stays in the entry with a red background until edited. A or B restarts a finished puzzle. A connected idle pad remains under human control. Returning to automatic play clears an unfinished entry and keeps submitted guesses.

The display shows the three most recent guesses, a six-dot attempt rail, the current entry, and letter feedback in the keyboard. D marks a daily puzzle; P marks practice. The upper-right A/P indicates automatic/pad play.

Uses `wordguess`, version 1.1.0, minimum firmware 0.3.2. The dedicated renderer is implemented on the local `task/app-lab-20261027` firmware branch and must be integrated before this package is published. Hardware validation is pending.

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
