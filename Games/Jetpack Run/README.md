# Jetpack Run

Fly through a neon lab, collect coins, and dodge lasers and incoming missiles.

Hold A or Up to rise and let go to fall. Shield orbs save you from one hit, missiles flash a warning before they come in, and the run speeds up as your score climbs. You get three lives, and A or B starts again. With no game pad it plays itself by the same rules.

It runs on the game engine, so its rules, art, and autoplay all live in `data/game.json`. It needs firmware 0.4.0-alpha.3 or later.

## Settings

- Game speed: slow, normal, or fast.
