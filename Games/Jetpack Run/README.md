# Jetpack Run

An original Joyride-style runner for mooboard. Hold A or Up to rise; release to fall. Collect coins and shield orbs. Dodge vertical zappers, horizontal lasers, and missiles with a flashing entry warning. The lab scrolls in layers, the jetpack flames animate, and speed increases with score. Three lives; A/B restarts. Automatic play uses the same rules.

All logic, original sprites, and automatic controls are game ABI 1 package data. No new native firmware renderer. Requires the universal runtime targeting firmware 0.4.1.
