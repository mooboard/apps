# Bomberman

Arrows move; A places a bomb with a 1.8-second fuse. Flames spread in a cross, stop at stone, destroy the first crate, and trigger other bombs. Defeat four roaming enemies and use the exit under the bottom-right crate. Flames can hurt the player too.

The game plays itself during its display turn. On boards with game controls, arrows and buttons take over. Three lives; A or B restarts after game over. Autoplay restarts automatically. Choose Slow, Normal, or Fast. Progress lasts for the current display turn.

Requires firmware 0.4.0 carrying the `bomberman` renderer. Original compact pixel artwork; no original arcade assets are included.
