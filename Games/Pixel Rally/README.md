# Pixel Rally

Race neon lanes, dodge traffic, chain passes, and manage your A-button nitro.

You get three lives, and A or B starts again after the race ends. With no game pad it plays itself and starts again on its own.

It runs on the game engine, so its rules, art, and autoplay all live in `data/game.json`. It needs firmware 0.4.0-alpha.3 or later.

## Settings

- Game speed: slow, normal, or fast.
