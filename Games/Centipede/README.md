# Centipede

Arrows steer within the bottom zone; A fires (hold to repeat). Mushrooms take three hits. Shooting a segment splits the remaining centipede into independent heads. Clear every segment to advance; watch for the spider.

The game plays itself during its display turn. On boards with game controls, arrows and buttons take over. Three lives; A or B restarts after game over. Autoplay restarts automatically. Choose Slow, Normal, or Fast. Progress lasts for the current display turn.

Requires firmware 0.4.0 carrying the `centipede` renderer. Original compact pixel artwork; no original arcade assets are included.
