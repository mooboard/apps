# Maze

When idle, the maze draws itself, grows an orange solution path, pauses and fades into the next maze.

Starting Play draws a fresh maze. Move the green dot to the red exit with the direction buttons. The orange trail records only the route you have walked; stepping back removes the last part of your trail. The game waits while you think and never reveals the solution during Play. Finishing a puzzle starts another after a short celebration. Closing Play returns to the animated idle loop.

Choose Slow, Normal or Fast to change the drawing animation's pace. Requires firmware 0.4.1 for this player-start and pause behavior.
