# Chrome Dino Runner

A desert runner that jumps cacti and ducks under swooping birds.

## Play

A or Up jumps. Down or B ducks. A connected idle pad stays under human control.

With no pad attached, the game plays itself. Pad play follows the firmware’s Gaming feature gate. Builds without that feature use automatic play.

This package requires firmware 0.3.2 with the dedicated engine merged from `task/app-lab-20261027`.

## Package

- Category: Games
- Renderer: `dinorunner`
- Version: 1.1.0
- Minimum firmware: 0.3.2
