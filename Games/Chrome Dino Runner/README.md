# Chrome Dino Runner

The iconic 8-bit desert runner sprinting across a scrolling pixel landscape.

Jumps over saguaro cacti and ducks under incoming pterodactyls with high-score tracking.

Playable with your phone's retro game controller in the web app, or watch it play itself on your wall.

## Settings

- Run speed: Slow, Normal, or Fast desert pace.

Configure game settings in your board's web app.
