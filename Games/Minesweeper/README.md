# Minesweeper

Classic logic puzzle uncovering hidden minefields through deductive reasoning.

Clears safe numbers, flags detected hazards, and cascades empty zones across a dense pixel matrix.

Playable with your phone's retro game controller in the web app, or watch it solve itself on your wall.

## Settings

- Solving pace: Slow, Normal, or Fast deductive sweep.

Configure settings in your board's web app.
