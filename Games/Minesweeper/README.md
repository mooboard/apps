# Minesweeper

A real 16×4 field with ten mines, numbered clues, flags, zero-cell flood fill, and chording. The first reveal and its neighbors are safe. Clear every safe cell to win.

Without a pad, a clue-based solver flags certain mines and opens certain safe cells. When clues leave an ambiguity it estimates local risk and guesses; it can lose. Solving pace sets the automatic player's delay.

On a board with Gaming enabled, the pad moves the cursor. A reveals a cell; A on a revealed clue opens its neighbors when its flag count matches. B toggles a flag. A or B starts a new field after a win or loss. An idle connected pad stays under human control. The right rail shows mines left to flag and cleared-field progress.

Uses `minesweeper`, version 1.1.0, minimum firmware 0.3.2. The dedicated renderer is implemented on the local `task/app-lab-20261027` firmware branch and must be integrated before this package is published. Hardware validation is pending. Games start a fresh field on each display turn.

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
