# Pixel Waterfall

Cascading mountain waterfall with rising mist and mossy stones.

## Implementation status

This source folder is a concept package. Its `uses` still selects the `rain` renderer. The named behavior needs its dedicated implementation connected before release. The icon refresh does not add that behavior.

## Package

- Category: Ambiance
- Renderer: `rain`
- Version: 1.0.1
- Minimum firmware: 0.3.1

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
