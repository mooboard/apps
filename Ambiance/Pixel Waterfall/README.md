# Pixel Waterfall

A mountain cascade with independent falling water strands, splash particles, moss-covered cliff ledges, wooded ridges, a rippling basin, and foreground river stones. Optional mist drifts around the impact. The scene runs locally and needs no clock, location, microphone, or network service.

Flow selects Gentle, Steady, or Powerful: it changes the curtain's width, falling speed, and splash rate. Mist switches the low drifting cloud on or off. Both settings apply during the current turn without resetting the scene.

Uses `waterfall`, version 1.1.0, minimum firmware 0.3.2. Its dedicated renderer is implemented on the local `task/app-lab-20261027` firmware branch and must be integrated before this package is published. Board validation is pending. Every display turn starts a new seeded landscape.

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
