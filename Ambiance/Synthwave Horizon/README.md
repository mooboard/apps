# Synthwave Horizon

A striped sunset above layered mountain silhouettes and an approaching perspective grid. Cyan road edges converge at the horizon, stars shimmer in the sky, and crossbars spread toward the viewer.

Travel speed selects Slow, Normal, or Fast. Palette selects Neon, Violet, or Ember. Both settings apply during the current display turn without restarting the scene. The animation runs locally and needs no clock, location, microphone, or network service.

Uses `synthwave`, version 1.1.0, minimum firmware 0.3.2. The dedicated renderer is implemented on the local `task/app-lab-20261027` firmware branch and must be integrated before this package is published. Board validation is pending. Each turn starts a seeded skyline and star field.
