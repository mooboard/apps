# Cyber City

A neon metropolis with distant towers, detailed foreground buildings, animated BAR/24H/NET signs, changing windows, street traffic, slanted rain, and distorted wet-road reflections. It runs locally as a nighttime scene and needs no clock, location, microphone, or network service.

Rain selects Off, Drizzle, or Downpour. Neon palette selects Neon (pink/cyan), Violet, or Amber. Both controls apply immediately while the scene keeps moving. The wet-road reflections remain visible in all weather modes.

Uses `cybercity`, version 1.1.0, minimum firmware 0.3.2. Its dedicated renderer is implemented on the local `task/app-lab-20261027` firmware branch and must be integrated before this package is published. Board validation is pending. Every display turn starts a seeded skyline.

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
