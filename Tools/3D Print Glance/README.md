# 3D Print Glance

Live 3D printer status on your desk for Bambu Lab, Klipper, Prusa, and OctoPrint.

Shows current layer progress, hotend and bed temperatures, and estimated time remaining.

## Settings

- Nozzle: label for extruder temperature.
- Bed: label for heated bed temperature.
- Nozzle color: color for the hotend temperature readout.
- Bed color: color for the bed temperature readout.

Adjust targets and manage print monitor cards in your board's web app.
