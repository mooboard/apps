# Timer

A countdown or a stopwatch you run from your phone.

Start a 1, 3, 5, 10, 15, or 30 minute countdown, add a minute, pause, or cancel. Big digits fill your mooboard, with a bar that shrinks as time runs out. It is one of the Clock app's timers, so it rings when time is up and keeps going after a restart.

The stopwatch counts in tenths of a second.

It stays on your mooboard while it runs. Run it in your board's web app.
