# Uptime Ping

Network latency and infrastructure ping health monitor on your desk.

Displays live millisecond response times to your local router gateway, DNS resolver, and cloud endpoints.

## Settings

- Gateway: label for primary gateway hop.
- DNS: label for public DNS benchmark.
- GW color: status color for gateway.
- DNS color: status color for DNS resolver.

Manage target hosts and alerting in your board's web app.
