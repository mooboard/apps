# Intervals

Work and rest rounds for your workout.

WORK shows in red and REST in green, with the round, the time left, and a bar. The last 3 seconds of each phase pulse.

## Settings

- Work: 20, 30, 40, 45, or 60 seconds.
- Rest: 10, 15, 20, or 30 seconds.
- Rounds: 4, 6, 8, 10, or 12.

It stays on your mooboard while it runs. Start, pause, skip, and stop it in your board's web app.
