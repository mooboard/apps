# Home Assistant Glance

Smart home environmental glance linked with Home Assistant and local sensors.

Renders room climate metrics, relative humidity, and air health status at a glance.

## Settings

- Room: name of the tracked room or zone.
- Sensor: secondary metric label.
- Temp color: temperature display color.
- RH color: humidity display color.

Control thresholds and sensor entities from your board's web app.
