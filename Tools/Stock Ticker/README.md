# Stock Ticker

Real-time market ticker and morning portfolio brief on your wall.

Tracks equities, index funds, and crypto tokens with bold numbers and 24-hour delta indicators.

## Settings

- Symbol 1: first watchlist ticker symbol.
- Symbol 2: second watchlist ticker symbol.
- Color 1: accent color for symbol 1.
- Color 2: accent color for symbol 2.

Configure symbols and morning brief inclusion in your board's web app.
