# Claude Usage Tracker

Your Claude Code session and weekly limits as two bars.

The top bar is your 5-hour session with the time until it resets. The bottom bar is your week with the day it resets. They
turn amber at 70% and red at 90%. When Claude Code hasn't sent anything for 15 minutes, the bars dim and show how long
it's been idle.

## Setup

Claude Usage Tracker needs Claude Code on a Pro or Max plan, a mooboard account, and a small script on your computer
that Claude Code runs as its status line. The script sends only the two percentages and their reset times. It never
reads or sends your Claude sign-in. Make a key on the app's page in your board's web app and add it to the script. At
home the script sends straight to your board, and away it sends through mooboard. Both carry the key, so nobody else on
your Wi-Fi can post numbers.
