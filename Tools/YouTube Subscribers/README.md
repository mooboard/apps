# YouTube Subscribers

Your channel's subscribers, views, or videos, as one big number.

It uses your own YouTube Data API key, which is free. Your board sends it only to YouTube.

## Get a key

1. Open console.cloud.google.com and make a project.
2. Turn on YouTube Data API v3.
3. Make an API key and paste it in the app's settings.

## Settings

- Your channel ID, such as UC_x5XG1OV2P6uZZ5FSM9Ttw, or your handle, such as @GoogleDevelopers.
- Your API key.
- Show subscribers, views, or videos.

YouTube rounds public subscriber counts to three figures.
