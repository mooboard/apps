# World Clock

Three global cities side by side with sun and moon markers.

## Implementation status

This source folder is a concept package. Its `uses` still selects the `sunmoon` renderer. The named behavior needs its dedicated implementation connected before release. The icon refresh does not add that behavior.

## Package

- Category: Clock
- Renderer: `sunmoon`
- Version: 1.0.1
- Minimum firmware: 0.3.1

The native 32×32 icon is generated by `builder/kit/redesign_icons.py`.
