# mooboard apps

Apps for mooboard, sorted by category. Each app is a folder: `<Category>/<app>/`.

| Category | Apps |
| --- | --- |
| Lifestyle | Prayer |
| Games | Coming soon |

Install apps from your board's web app: Home, then Add.

To make your own app, start with the [dev kit](https://github.com/mooboard/dev-kit).
